# 検証チャート復旧版（2026-08-06）

## 保存方針

このフォルダは、元の `20260628` フォルダとは別の**復旧専用コピー**です。元データを上書きせず、このフォルダを丸ごとバックアップ対象にします。

R2は歩み値CSVの保管場所です。ブラウザ画面・JavaScript・ローカル設定・EP/TP記録は別途このフォルダまたはブラウザのローカル保存領域に残ります。R2にアプリ本体の世代バックアップはありません。

R2公開URLはブラウザから直接読むためのCORS許可がないため、`fetch-r2-symbol.py 5803` で取得した日別CSVをローカル配信します。取得後は `local-r2-manifest.json` が自動作成され、Safariには実データだけが表示されます。

6〜8月の全日分のように、R2の非公開一覧から同期する場合は `sync-private-r2-symbol.py 5803` を使います。このスクリプトは認証情報を保存せず、実行時の環境設定だけを利用します。チャートは日別CSVを使って軽く読み込み、同時に日付順の結合CSVをバックアップとして作成します。

## 復旧済み機能

- R2銘柄ツリー、期間指定、複数日CSVの読込・結合
- Z / X リプレイ、時間足切替、日足・2分・10分・15秒足
- 水平線、レイ、VWAP、出来高キャンドル、板／約定プロファイル
- RR計測（ENTRY → LC → TP）、価格ラインのドラッグ
- EP（推奨エントリー）／TP（決済）をチャートクリックで保存。EPはBUY/SELLとメモ、TPはメモを残せます。
- 実取引CSVを取込むと、実際の ENTRY（IN）と決済（OUT）を銘柄・時刻・価格ごとに表示できます。標準は非表示で、ツールバーの「実取引: OFF / 1 分足 / 2 日別」で切替ます。
- 4銘柄15秒足。Z / X は4画面へ同時反映します。

## EP / TP の保存先

ブラウザごとのローカル保存です（Safariの同じプロファイル内）。銘柄別に保存されます。ブラウザデータを消去すると記録も消えるため、将来はJSON書出しまたはSQLiteへ移します。

実取引履歴もローカルの `actual-trades.json` に保存し、GitHubには送信しません。新しい履歴はツールバーの「取引CSV」から追加できます。
