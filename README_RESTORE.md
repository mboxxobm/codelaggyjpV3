# 検証チャート復旧版（2026-08-06）

## 保存方針

このフォルダは、元の `20260628` フォルダとは別の**復旧専用コピー**です。元データを上書きせず、このフォルダを丸ごとバックアップ対象にします。

## 復旧済み機能

- R2銘柄ツリー、期間指定、複数日CSVの読込・結合
- Z / X リプレイ、時間足切替、日足・2分・10分・15秒足
- 水平線、レイ、VWAP、出来高キャンドル、板／約定プロファイル
- RR計測（ENTRY → LC → TP）、価格ラインのドラッグ
- EP（推奨エントリー）／TP（決済）をチャートクリックで保存。EPはBUY/SELLとメモ、TPはメモを残せます。
- 4銘柄15秒足。Z / X は4画面へ同時反映します。

## EP / TP の保存先

ブラウザごとのローカル保存です（Safariの同じプロファイル内）。銘柄別に保存されます。ブラウザデータを消去すると記録も消えるため、将来はJSON書出しまたはSQLiteへ移します。
